# Hospital-Management-System

1. Project Overview

Project Name: Hospital Management System
Domain: Healthcare
Technology: MERN Stack
Frontend: React.js, HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB
Core Problem: Simplify hospital-related activities through a centralized web application.
Primary Goal: Provide user authentication, admin access, appointment booking, and messaging functionality in one platform.

2. Objectives

- Develop user signup and login functionality.
- Implement separate admin signup and login functionality.
- Provide an appointment booking facility for users.
- Enable users to send messages through the application.
- Integrate frontend and backend components.
- Store and manage application data using MongoDB.
- Build a user-friendly and maintainable web application.

3. Key Features

User Authentication
- User registration and login.

Admin Authentication

8. Getting Started

Prerequisites

- Node.js and npm
- MongoDB
- Git

Installation

1. Clone the repository:

git clone YOUR-REPOSITORY-URL

2. Navigate to the project directory:

cd Hospital-Management-System

3. Install frontend dependencies:

cd frontend
npm install

4. Install backend dependencies:

cd ../backend
npm install

5. Configure the required environment variables, including the MongoDB connection string, in the backend .env file.

6. Start the backend and frontend using the scripts defined in their respective package.json files.

Note: Folder names and commands may vary depending on your project structure.
